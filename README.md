# chardev-lab

Laboratorio para entender, probar y diagnosticar un character device Linux.

## Objetivos

- Entender cómo funciona un character device.
- Probar read/write desde userspace.
- Observar comportamiento con acceso concurrente.
- Documentar experimentos.

## Estructura

- `kernel/`: módulo del kernel.
- `userspace/`: herramientas de prueba en C.
- `docs/`: notas de experimentos.
